# Pcode

**轻量级终端编码 Agent** —— 不只是聊天框：它动手读代码、改文件、跑测试拿证据，
并且解决了 Agent 真正难的部分：**长会话下的上下文治理、知识的自进化积累、能力的边界控制**。

个人从零实现，设计思想受 **Claude Code** 与 **MiniCode-Python** 启发，全部代码自己写。

---

## 核心特性：四大子系统

### 1️⃣ 分层上下文压缩 —— "摘要预览 → 占位替换 → 按需检索 → 超限兜底"

Agent 的第一杀手是上下文膨胀。Pcode 用两个层次治理它：

- **字节层 · 工具输出外置（TOOL_BUDGET sweep）**：每步出账前扫描，超过 2000 字符的旧工具结果
  全文落盘存档（自描述元数据头：工具名/时间/参数），上下文只留"存档通知 + 头尾预览"。
  单条 25000 字符 ≈ **97% 瘦身，零 LLM 成本**，需要时按存档路径回读；
- **语义层 · FULL 压缩**：估算 token 超阈值时，旧对话请模型总结为 `[历史摘要]`；
  防滚雪球设计——已有摘要作为合并基底全文传入，阻断"摘要的摘要"失真链；
  配对保护保证 `tool_calls/tool` 结构永不被切断；
- **撞墙抢救（reactive rescue）**：上下文超限异常的识别与就地压缩恢复；
  断点悬空修复——上次崩溃遗留的未配对 `tool_calls` 自动补占位结果，会话永不卡死；
- **两世界持久化**：运行世界与持久世界解耦，增量保存为主、边界全量追平；
  transcript 无损卷宗永不压缩，`/replay` 可审计全程。

### 2️⃣ 自进化记忆沉淀 —— "执行 → 反思 → 提炼 → 分类存储 → 索引更新 → 按需复用"

跨会话的经验闭环，且**进化不靠人策展**——三件套是真实存在的选择压力：

- **变异**：反思引擎四张网（错误/决策/事实/工具）零 LLM 扫描任务切片，
  算术置信闸门过滤——纯失败（没有解法的坑）数学上入不了库；
- **选择**：注入过的记忆随任务成败 **±2/−1**，检索排序读该计数——
  好用的记忆逐任务浮上来，误导性的逐任务沉底；
- **遗传**：策展人每 10 个任务一轮（全系统唯一花 LLM 的地方，≤2 次调用）——
  近重复合并（Jaccard ≥ 0.85）、验尸过时标记（引用文件已消失）、相似簇熬成洞见（记忆长出元记忆）。

存储双格式：`memory.json` 唯一事实源（完整元数据）+ `MEMORY.md` 人类可读投影（只读，每次重生成）；
原子写入；容量三重封顶（200 条 / 25KB / 最老优先逐出）。

### 3️⃣ Skill 能力体系 —— "原子工具 — 高层 Skill — 技能菜单"三层路由

程序性知识（怎么做成一类事）与原子工具（单步动作）分层组织，意图驱动召回：

- 技能菜单以"名称 + 描述"一行摘要**幂等渲染**进 system 尾部（保住 Prompt Cache 前缀）；
  全文经 `load_skill` 元工具按需精读——技能常驻成本从全文级压到**菜单行级（10~30×）**；
- **渐进披露 / 直接加载**双检索模式，按技能库规模自动切换；
- 双根目录：项目级 `.pcode/skills/` 覆盖用户级 `~/.pcode/skills/`，一个 `SKILL.md` 即一个技能；
- 召回粗选由模型在菜单上完成（意图识别的执行者是模型，工程侧保证匹配面的信息密度）。

### 4️⃣ 权限与安全审查 —— 多层审查链路，fail-closed

- **规则过滤**：16 条危险命令规则（灾难删除 / 磁盘 / 系统 / 出界影响 / 远程执行 / 环境变更），
  永远生效、零成本、拦在 `subprocess` 之前；
- **工具自检**：自我修改边界——工具不允许写 `~/.pcode/`（记忆/技能/会话是 Agent 的"自我"，
  改它们 = 越权修改自己的能力边界）；
- **AI 风险分类（prompt 注入防御）**：外部内容（HTTP 响应）进上下文前打"来源围栏 + 防御语"，
  把数据/指令的边界显式画出来；
- **人工确认**：危险命令弹出 y/a/n 确认面板——`y` 仅一次（会话级免重复问）、
  `a` 本会话总放行、`n` 拒绝且原因回传模型换方案；"总是允许"落盘账本跨会话生效；
- **fail-closed 哲学**：无确认通道时危险命令一律拒绝；软防御（围栏）降低被骗概率，
  硬防御（权限）限制被骗损失——模型被骗的那一刻，手里也没有能造成不可逆伤害的工具权限。

## 架构总览

一个任务的一生，四次穿过四套系统：

```
用户敲下任务
   │
   ├─【记忆】检索库内经验 → 相关度门槛 top-3 → 拼进任务消息开头（尾部注入，缓存全保）
   ├─【Skill】技能菜单常驻 system 头 → 模型按意图 load_skill 精读全文
   ▼
工具循环（最多 50 步，相位系统跟踪 explore→execute→verify）
   ├─【压缩】每步出账前 sweep 外置旧工具结果；token 超阈值触发 FULL 摘要
   ├─【安全】每条命令过 16 条规则；危险 → 人工确认；外部内容打围栏
   ▼
任务落幕（正常交付 / 步数耗尽 / 异常崩溃）
   ├─【记忆】反思四网扫描 → 算术闸 → 入库；当事记忆 ±2/−1；每 10 任务策展
   ├─【压缩】两世界同步：增量落盘 + transcript 无损卷宗
   └─【安全】异常出口不反思但追责（记忆 −1）
```

## 设计公理

五个子系统共享同一套底层判断——这是"一个架构"而非"五个零件"的证据：

1. **热路径零 LLM，贵操作低频化**——反思每任务免费跑，策展 10 任务批处理一次；
2. **fail-closed**——拿不准的操作拒绝而非放行（危险命令、自我修改、越界路径）；
3. **器官可摘除，宿主无感**——记忆/安全系统损坏或关闭，主流程照跑；
4. **事实源与投影分离**——`memory.json` 是唯一事实，`MEMORY.md` 是可再生投影；
5. **Prompt Cache 前缀神圣不可侵犯**——尾部注入、占位替换、幂等渲染，三处同一公理。

## 快速开始

```bash
git clone https://github.com/pls123s302/Pcode.git
cd Pcode
pip install -e .
pcode
```

首次运行前配置 OpenAI 兼容接口（默认 DashScope qwen-plus，任何兼容端点均可）——
创建 `~/.pcode/settings.json`：

```json
{
  "api_key": "sk-你的Key",
  "model": "qwen-plus",
  "base_url": "https://dashscope.aliyuncs.com/compatible-mode/v1"
}
```

## CLI 命令

| 命令 | 作用 |
|---|---|
| `/tools` | 查看当前工具箱 |
| `/new` | 开新会话 |
| `/sessions` | 列出本工作区历史会话 |
| `/resume latest` / `/resume <id>` | 恢复会话（跨工作区恢复亦可） |
| `/replay` | 回放本会话完整流水账（transcript 永不压缩，久远细节都在） |
| `/help` · `/exit` | 帮助 · 退出 |

## 工具与扩展

| 层 | 内容 | 加载策略 |
|---|---|---|
| 核心层 | `list_files` `read_file` `write_file` `edit_file` `run_command` `file_tree` | 常驻（schema 每请求在场，暴露面最小化） |
| 扩展层 | `http_request`（外部内容自动打来源围栏） | full 档懒加载 |
| 元工具 | `load_skill` / `find_skill`（技能精读 / 检索模式召回） | 有工作区即注册 |
