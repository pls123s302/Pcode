# Pcode

一个轻量级终端编码 Agent——能读懂你的项目、修改代码、运行测试，
在终端里以清晰好看的方式展示它做的每一件事。
（受 MiniCode / Claude Code 启发的个人从零实现）

## 定位
- 给谁用：我自己的日常开发 + 课程答辩演示
- 一句话卖点：不只是聊天框——它动手改代码、跑测试拿证据，
  并且把它做的每一步都漂亮地摊开给你看

## 工具集（5 个，全都在真实文件系统上工作）
| 工具         | 能力                     |
|--------------|--------------------------|
| list_files   | 浏览项目结构             |
| read_file    | 带行号读文件/代码        |
| edit_file    | 精确替换式修改           |
| write_file   | 新建或整体重写文件       |
| run_command  | 跑测试/任意命令（带门禁）|

## 用户故事（= 验收标准）
1. "统计并运行 tests 目录下所有测试" —— Pcode 列目录→读文件→跑 pytest→汇总结果
2. "修复 main.py 里的除零 bug" —— 读代码→定位→修改→跑测试验证→汇报
3. 全程终端界面：工具调用显示为彩色面板，回答以渲染后的 Markdown 呈现，
   思考时有加载动画——好看到我愿意截图
4. 危险命令（删除/格式化类）必须经我确认才执行

## 明确不做（V1 Non-goals）
- 不用全屏 TUI 框架（Textual 等），用 rich 美化传统 REPL
- 不做 MCP 客户端、多模型路由、并行工具调用
- 不做后台任务/定时任务

## Backlog（V2 候选，本期不做）
- 会话持久化：/sessions、/resume、/replay
- 编辑快照：checkpoint + /rewind
- 相位系统：explore/execute/verify + /readiness 体检

## 设计决策
- D1: 工具调用用 Function Calling，不自造文本协议 —— 协议正确性由 API 保证
- D2: 命令本机直跑 + 危险命令审批门禁，不造沙箱 —— 本地优先，git 兜底
- D3: 终端美化用 rich，不引入 TUI 框架 —— 好看与简单之间取平衡
